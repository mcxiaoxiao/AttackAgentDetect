\section{Method}
\label{sec:method}

Each trace is represented by allowlisted command names and distinctive artifact-name tokens. The command component is the cosine similarity between training-fold TF--IDF vectors. For the artifact component, generic tool and path terms are removed and each remaining token receives an inverse-document-frequency weight fitted on the training traces. The score is the weighted overlap divided by the weighted mass of the shorter artifact signature:
\begin{equation}
\label{eq:pair-score}
S(x,y)=0.45\,\operatorname{cos}_{\mathrm{TF--IDF}}(x,y)
+0.55\,\operatorname{contain}_{\mathrm{IDF}}(x,y).
\end{equation}
This asymmetric containment preserves evidence shared with a short trace when the other trace contains additional commands or artifacts. Unseen test-time artifact tokens use the maximum weight learned from training data. The score is not calibrated as an identity probability.

For each outer task-held-out fold, the decision threshold is chosen from inner task-grouped out-of-fold predictions in the training partition and then held fixed for the test partition. The command-only TF--IDF baseline follows the same evaluation protocol.
