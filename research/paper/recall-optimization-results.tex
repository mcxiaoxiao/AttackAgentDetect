\section{Nested experiments to reduce missed associations}
\label{sec:recall-optimization}

We ran four fixed, nested task-held-out experiment rounds on the same 177 public traces, 40 benchmark-qualified task groups, and three CTF benchmarks. The 20\% training false-merge target remained fixed. Each outer fold held out complete tasks; all threshold and candidate selection used training-fold tasks. Intervals are paired benchmark-stratified task-cluster bootstrap intervals with 5,000 draws. The cohort had already been inspected during development, so these results are exploratory rather than independent confirmation.

We assessed ten metrics: overall false-split rate (FSR), false-merge rate (FMR), Human--Agent (H--A) FSR/FMR, balanced accuracy, query coverage, Hit@1, MRR, Recall@5, and NDCG@5. Lower error rates and higher values for the remaining metrics are preferred. Changes below are percentage points relative to the behavior-only baseline.

Across the four rounds, every candidate traded one error type against another. Mode-stratified thresholds improved several error-rate estimates but increased Human--Agent FMR; query-rank fusion reduced FSR and Human--Agent FMR but raised overall FMR. Threshold-only policies left ranking unchanged, while learned fusion produced near-zero ranking shifts. No candidate improved all ten metrics on the held-out development tasks. The table retains the complete prespecified metric comparison; the per-round search details are in the experiment log.

Error analysis suggests two unresolved representation problems. The median shorter-to-longer trace-length ratio was 0.40 among positive pairs missed by both the baseline and the 24D-profile ranker, compared with 0.75 among positive pairs found by both. Separately, 12 groups of cross-task traces shared an identical normalized command sequence; the largest group contained 18 traces from 13 tasks. These observations motivate partial-coverage matching and evidence beyond generic command names, but do not establish that either feature will improve generalization.

The available traces also confound execution mode with collection interface: 300 Python tool calls appear in 70 Agent traces and none are represented on the Human side. These fields are excluded from shared behavior features. Same-task labels denote a CTF retrieval proxy, not a common operator, attacker, or organization. A confirmatory test requires new task groups with Human, Agent, and Script behavior collected through comparable telemetry and frozen evaluation splits.

\section{Follow-up development: recall-first artifact containment}
\label{sec:balanced-innovation-v11}

After correcting Human terminal-command reconstruction, we tested whether a distinctive artifact shared by a short and a long trace could avoid the length dilution of ordinary Jaccard similarity. The v11 score combines command TF--IDF with IDF-weighted containment of artifact-name tokens in the shorter trace. Among thresholds passing every inner-fold hard gate, the selector chose the lowest cutoff. The cohort contains 97 matched traces in the same 40 task groups, with one Claude Sonnet Agent trace per task. This is a reused development cohort; it is not independent confirmation.

The selected policy accepted all 148 observed directed same-task candidate pairs and had no missed-link event in the 40 positive task groups. The ordinary bootstrap interval for absolute FSR is degenerate at zero. As a sensitivity check, if task groups are treated as independent clusters, 0 events in 40 clusters gives a one-sided exact 95\% upper bound of 7.2\% on the share of task groups with any miss; this is not a confidence interval for task-macro FSR. The paired FSR change is reported above. Although both error-rate point estimates fell and no outer fold had a higher FSR than its same-fold baseline, absolute FMR remains 75.87\%, so the method is not suitable for attribution.

Hard-negative verifier diagnostics expose a different tradeoff: the generic verifier reached 19.1\% FMR at its inner utility threshold but had 16.9\% FSR. Human/Agent conditioning yielded 23.2\% FMR and 18.2\% FSR. Removing the Human profile raised FMR to 24.5\%, while removing the Agent profile lowered it to 21.6\%. These mixed ablations do not establish a stable source-specific profile benefit. Exhaustive scanning of every observed verifier-score threshold in v13 still found no inner-fold point satisfying all hard gates; the selector fell back to the command baseline. The results therefore support further study of artifact and neighborhood evidence, but not a claim that Human/Agent profiling has solved association.

The v14 query-local rank-cap policy evaluated every $k\in\{1,\ldots,60\}$ for the v11 artifact score. No $k$ passed all inner gates in any outer fold, so all three folds retained the command baseline. In fold 1, $k=1$ reduced inner FMR from 54.9\% to 5.1\% but raised FSR from 1.23\% to 30.4\%; $k=9$ restored FSR to 1.23\% while FMR rose to 87.5\%. In fold 2, $k=5$ reduced FMR from 84.7\% to 76.5\% and preserved FSR, but lowered query coverage from 99.38\% to 98.15\%. In fold 3, $k=5$ reduced overall FMR from 86.8\% to 75.7\%, but failed the Agent--Agent FMR and query-coverage gates. Because the rank cap only changes the decision boundary, it leaves the underlying ranking metrics unchanged. This failed round shows that a fixed candidate count cannot resolve query-to-query variation or the profile-dependent ordering of hard positives.
