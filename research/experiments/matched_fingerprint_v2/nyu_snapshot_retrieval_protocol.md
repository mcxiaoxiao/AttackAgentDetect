# Matched cross-challenge snapshot retrieval

Use the pinned local NYU D-CIPHER transcript revision and the eligible trace manifest from the task-association study. Include each challenge with exactly one eligible trace from each of the four known submissions. Define the target as the same submission snapshot. For every query from challenge A, all four candidates come from a different challenge B, with one candidate per submission. Evaluate every ordered challenge pair within each test fold. Hold out entire challenges in three SHA-256 assigned folds. The model sees only pair features and trains on other challenges. It never sees challenge names or submission metadata at scoring time. The task-association models, threshold and prediction files do not enter this analysis.

Use a fixed logistic loss on positive-minus-negative feature differences, C=0.1, equal mass for each training gallery, and four-event windows with mean and SD pooling. Compare length alone, E with length, B/S alone, and E with length plus B/S. Length uses absolute log-length difference and mean log length. Standardize pair inputs on the training folds and scale the B/S columns by 0.5 after standardization. Fit preprocessing independently in each fold. The primary contrast is E+length+B/S against E+length. Rank outcomes are gallery AUC and Hit@1. Chance is 0.5 and 0.25, respectively.

Repeat the analysis on the common subset in which all four traces contain at least eight commands. Score both the full traces and exactly the first eight commands of each trace on the same task pairs. Treat a positive full-trace AUC interval as an exploratory signal. Require the equal-prefix AUC interval to be above zero before claiming that the increment persists at equal observed length. Use 10,000 paired task bootstrap draws within each fold. Resample task IDs jointly in both the query and candidate roles. Freeze this bounded batch before running and retain all arms. This study can estimate cross-challenge retrieval of these four known submission configurations within D-CIPHER.

After observing the eight-command result, record a secondary fixed-length sensitivity. On the subset with at least 16 observed commands in all four runs, compare the first eight, first 16, and all observed commands on the same tasks and folds. Use the identical model, features and resampling procedure. Report all three results as exploratory and retain the original eight-command control on its larger cohort.
