# CTH gallery ranking experiment

Use the 17 CTH development tasks, their three existing outer folds and all 54,400 frozen candidate decisions per arm. Use the original XGBoost E and E+B/S scores and decisions as reference arms. This experiment has one bounded batch with four matched logistic arms, six inner fits and three outer fits, a ten minute execution budget, and seed 20261105. NYU and the Agent-only CTH panel are outside the run.

Compare a pointwise binary logistic loss with the logistic loss on same-query positive-minus-negative feature differences. Both use every eligible directed training pair, equal task mass, equal query mass within a task, and equal positive and negative mass per query. The feature contrast is E against E+B/S. Both B/S learners use the same four-event, mean/SD, command-conditioned representation and the same two relative scales, 0.25 and 1. Both losses use C in {0.01, 0.1, 1}. Scaling, imputation and vocabularies fit on training traces. If any candidate in an evaluation gallery lacks either B/S block, every candidate in that gallery uses the corresponding E model's score and threshold. Whole-gallery fallback keeps all scores on one model scale.

Choose C and B/S scale by inner task-macro gallery AUC, breaking ties by Hit@1, then smaller C and smaller scale. Select a threshold from the same inner scores by the existing pooled FMR ≤10% rule. Inner folds use 20 seeded four-candidate draws per query. Outer decisions use the identical CTH candidate manifest and original five exact role shares.

The primary test is paired change in gallery AUC of the rank loss versus the pointwise loss with the same feature view. Report Hit@1, AP, BA, FMR and FSR as secondary diagnostics. A method-level improvement requires a positive paired AUC interval against the matched control. Automatic association requires FMR and FSR both to decrease against the reference and the held-out FMR to meet the 10% operating target. Use 10,000 paired query-task bootstrap draws and inspect each outer fold. The results describe development tasks previously examined in the project.
