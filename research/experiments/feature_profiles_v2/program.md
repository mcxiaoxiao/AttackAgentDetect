# 行为画像特征扩展 v2：冻结实验协议

2026-10-30。目标：区分 Human/Agent 轨迹来源标签并保存可比较的行为特征；检验更多特征是否改善已有命令词汇基线。当前语料的标签与采集接口混杂，不能解释为真实操作者识别或组织归因。

- 数据：既有固定版本 CTH 177 条非空轨迹、40 个 benchmark/task 组；CC BY 4.0。已有分析看过该队列，因此所有结果均为探索性复用，不称作独立测试。
- 单位：整条轨迹；分组切分先于任何表示学习。各题目内计算指标，再对题目、基准等权平均。窗口不作为独立样本。
- 预算：本地 CPU，一批固定方案，最多 20 分钟，无付费 API、不下载新日志。新增实现和输出使用独立路径；不覆盖 v1 结果、不提交其他工作区改动。
- 主指标：平衡准确率（BA）；次指标 macro-F1、AUROC、Human/Agent recall、Brier。阈值固定 0.5；没有校准阶段，不称真实参与概率。
- 原假设：24 项扩展统计相对命令 TF-IDF 没有稳定增量。候选解释：重复、集中度及前后分布变化提供词汇之外的信息。竞争解释：长度、压缩头开销、任务构成或采集接口造成表面增益。
- 固定比较：命令 TF-IDF（F1）；历史 F3（F1+旧9项结构）；24项数值；F1+标准化24项（权重1）；F1+去掉显式长度相关项的21项（去掉命令量、gzip比、短轨迹标记）；训练内选择基线或24项融合权重0.1/0.3/1的逻辑回归。
- 主评估：与 v1 相同的6个种子、按基准分层的3折任务留出。词表、缺失值中位数、标准化、融合权重选择只使用训练数据；内层3折仅选择融合权重，外层评价选择流程。若所有内层表现相同，优先较简单模型。固定逻辑回归 C=1、class_weight=balanced、max_iter=3000。
- 诊断：同一队列前4条命令（仅 n>=4）、完整序列打乱（命令和动作配对）、留一基准、任务与Agent模型共同留出。固定比较基线与内层选择流程，不能根据诊断改方案再重看同一结果。
- 不确定性：先对每题6个种子取均值，再在基准内对题目分层配对bootstrap 5,000次；重复切分不当作独立重复。多组结果用于探索，不择优宣称已确认提升。
- 保存：24项特征清单、逐轨迹值及缺失原因、折外判别分数、分组清单、模型配置和代码/输入哈希。训练真值独立保存在评估侧，不写入推理特征。
- 缺失：字段不足记 null；空轨迹不强行分类。不同来源格式不得共用公共库检测器。时间、失败、参数、TTY、进程树、TTP标签、跨Agent消息暂不进入本轮模型。
- 停止：完成固定批次即停止；失败记录为失败，不生成替代数字。即使无提升，保留画像导出与负结果。默认公共检测器不自动替换。

特征来源核对：AIT/AECID upstream README 列出8类37项，实际34项进入其统计检验；这不等于“37项都有效”。只查阅公开方法说明和代码定义，不复制未明许可的上游实现或下载其数据。项目24项是独立实现的候选集合，不冒称文献标准。
