## Mode-readout follow-up

A second fixed batch evaluates two C=1 models: command+predicted mode and command+B/S+predicted mode. Mode predictions use only fingerprint summaries and are cross-fit over three training-task folds for training pairs; test scores use the outer-training fit. The pair features are predicted HH/HA/AA probabilities and their command-cosine interactions. True test mode is never an input. Both results are retained, with unchanged outer galleries and task-cluster intervals.
