# 补充预设：Trace 风格的分类基线

相关工作检索确认，Trace 已在 2026 年直接研究从攻击 Agent 的终端命令序列识别底层模型家族，并报告 TF-IDF 与线性 SVM 的结果。因此，单纯提出命令日志分类不能作为本项目的创新点。本补充检查只回答：在本项目已有的公开人类/模型任务轨迹上，采用相同类别的轻量文本分类器是否能复现一个可运行基线。

在第一轮和事后混杂检查的任务划分、筛选规则与测试集上固定使用 TF-IDF 一元及二元命令词和线性 SVM（`C=1`、类别权重平衡），不网格搜索，不根据测试集调参。按任务进行 bootstrap 区间估计。该实验是对另一数据集和另一分类目标的算法迁移检查，不是 Trace 复现，也不与其 7 类模型识别结果直接比较。

无论表现如何，分类标签都只能解释为该数据集的人类实验样本与所选模型生成样本；日志采集方式不同，且没有传统脚本和真实攻击组织标签。新结果只为下游关联实验提供一项对照。
