# 实验现状与下一步验证

更新：2026-11-03

## 研究问题与定位

调查者通常先接触已经留存的日志，未必知道背后的模型、框架、提示或工具配置，也未必能主动探测执行系统或把系统接入统一沙箱。本文从常见日志字段构造可解释的行为指纹，并分别评估两个读出：一是预测来源记录的 Human／Agent 执行方式标签；二是直接将指纹距离加入命令或请求证据，检索任务相关轨迹。

研究假设是：同一任务切换执行方式可能改变操作路径；不同任务使用相似执行系统可能带来共同操作习惯。二者都需实测，不能预设关联错误一定随 Agent 比例上升。本文不试图从有限日志识别具体大模型或产品，也不把同题标签解释为同一操作者、攻击活动或 campaign。

## 数据和观测范围

| 队列 | 可用样本 | 关系／标签 | 用途 |
| --- | --- | --- | --- |
| 原关联面板 | 97 条轨迹、40 题、1,558 条配对 | 同一基准题 | 保留命令与产物旧基线 |
| CTH 全部双类题 | 40 题；177 条原始轨迹，其中 175 条可计算（57 Human、118 Agent） | 同一来源内的题目 | 五折任务留出跨方式检索 |
| CTH 配比核心 | 17 题、85 条轨迹（34 Human、51 Agent）；84 条进入窗口计算 | 同一来源内的题目 | 0／25／50／75／100% 精确 Agent 配比 |
| AIT | 109 次排障运行（61 Human、48 Agent），另保留旧 89 次子集 | 数据发布的 Human／Agent 标签 | 任务与来源留出识别、实测启动节奏 |
| Honey for the Agent | 13,080 条合格会话、9 个模型快照、49 种条件 | 同提示、轮数与环境下的跨模型快照检索 | Agent-only 压力测试与执行耗时消融 |
| CyBiasBench | 450 场指定攻击家族会话、258,019 条请求、5 个 Agent、3 个目标 | 目标与指定攻击家族条件 | HTTP 路由序列留一目标检索 |
| 可下载目录 | 1,407 条来源限定的轨迹／任务记录（344 Human、1,063 Agent） | 多来源任务键 | 浏览、复现与字段覆盖；不作为一个混合分数 |

外部 Honey、CyBiasBench 的原始会话没有并入 1,407 条下载包；结果仅保存聚合指标及可追溯来源。各来源的观测单位、时间字段和关系标签都分别说明。

## 表示与实现

行为指纹以 8 个事件为局部窗口，按轨迹长度生成可变行数 J。B8 描述局部命令与动作组织，S8 描述新工具、重访、回返、片段复用和窗口变化，T8 只计算来源实际记录的间隔／耗时特征。B+S 矩阵为 J×16；有实测时间时为 J×24。每个特征的均值、标准差和沿窗口位置的趋势组成 48／72 项分类读出。取消旧的整轨迹 16 命令门槛，保留来源各自最低有效窗口与缺失掩码。Honey 的命令执行耗时不冒充命令启动间隔。

识别分支与关联分支分开：识别使用来源标签并按任务／采集组留出；关联把行为、顺序距离直接融合进命令或 HTTP 路由相似度，不依赖先判定 Agent 身份。题目、来源、模型、任务结果等元数据不进入指纹特征。

## 已完成结果

| 实验 | 主要结果 | 当前解释 |
| --- | --- | --- |
| 原命令／产物基线 | Hit@1 29.60%→79.31%；任务宏 BA 57.35%→62.06%；最终 FMR 75.87% | 产物证据提高排序，但仍有大量误合并；不是新指纹比较 |
| CTH 17 题配比 | 加入 B/S 后五档 BA 点估计提高 2.0–5.5 个百分点；每档配对任务簇区间都跨零；Hit@1 不稳定 | 结果显示错误取舍可随配比变化，但无可靠的单调趋势或增量 |
| CTH 全 40 双类题跨方式检索 | 命令 Hit@1 33.65%；命令+B/S 为 33.56%；Δ −0.08 pp，95% 任务簇区间 [−5.71,+5.58]；随机基线 12.5% | 扩展覆盖后，尚未显示 B/S 增益 |
| AIT 标签识别 | 扩展 109 条，B+S+T 任务留出 BA 68.8%，命令 TF–IDF 95.1%；来源留出分别 52.6% 和 85.4% | 标签与任务流程和采集路径混杂；命令词汇预测高分不等于识别操作者 |
| AIT 时间消融 | 加 T 后，冻结 89 条任务留出 ΔBA +15.1 pp [+3.3,+26.7]；扩展 109 条 +15.8 pp [+6.1,+25.0] | 存在来源特定时间信号；冻结队列来源留出变化区间跨零 |
| Honey | B/S 对 Hit@1 −1.30 pp [−2.21,−0.35]；加观测执行耗时 Δ −0.35 pp [−0.87,+0.16] | 没有检索收益；真实耗时和事件间隔是不同字段 |
| CyBiasBench | 路由 Hit@1 39.02%→39.94%；FMR 13.6%→2.8%，FSR 74.7%→92.8% | 三个目标簇上的描述性取舍，不是可靠的平均增益 |

50% CTH 配比下，HH／HA／AA 按单对执行方式分层。命令基线的正例 FSR 分别为 45.1%／81.9%／73.3%；命令+B/S 为 25.6%／76.5%／62.8%。融合同时改变 FMR，因此不能把某一对类型的下降单独解释成总体改善。这些重复配比判定不是独立攻击活动样本。

## 后续验证顺序

1. **冻结当前版本和分割。** 保存 B/S/T 实现、来源清单、任务分组、固定候选生成、阈值选择规则和所有已尝试模型，确认特征没有读取执行标签或任务元数据。
2. **先复核现有实验。** 在同一任务划分与候选下重现原命令／产物、CTH 配比、40 题跨方式检索、AIT 识别和时间增量、Honey 与 CyBiasBench；对每项报告 BA、FMR、FSR、Hit@1、MRR、覆盖与簇级区间。
3. **评估预声明消融。** 比较 B、B+S、B+S+T；在有效时间队列比较实际时间字段与时间缺失；做窗口顺序和时间顺序扰动，并用命令数量、可见长度、事件耗时作控制。训练侧按任务分组选择模型与参数，测试侧不用于选型。
4. **做跨来源和字段适配压力测试。** 对每个来源分别报告留出任务／执行配置／目标结果；模拟缺失时间、未知命令类别和短轨迹，记录适用覆盖。三个目标的 CyBiasBench 只报告目标范围，不制造伪精确的查询级置信区间。
5. **必要时再设计独立外部真值验证。** 当前资源没有真实活动、campaign 或共同操作者关系标签，故暂不声称这些关系的改善。若以后需要检验现实活动关联，应先确认可公开复核的活动级真值与观测字段，再决定数据方案；本轮不安排新增真人采集。
