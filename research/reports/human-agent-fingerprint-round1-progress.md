# Human/Agent 行为指纹：新一轮进展

日期：2026-11-01。状态：已完成文献与日志可行性调研、核心指标规范、历史输入审计、95次运行的标量分类预实验，以及1,142条记录的多源轨迹目录。时间窗口指纹矩阵与新增关联实验尚未完成。

## 主线与本轮决策

主线为从可见执行记录构建可解释行为指纹矩阵，检验执行方式对任务轨迹关联的影响，以及矩阵直接加入关联方法的增量价值。Human/Agent识别为相关的独立终点，不强制作为关联的中间步骤。CTF采用同题标签，漏洞与命令分域保留各自任务和条件；不预设这些标签代表同一幕后人员或组织。不使用 SVD、HOSVD 或 TSA。

根据实际可取得的通用日志，21 项宽候选收缩为 **8 项核心序列指标**。六组21项定义保留为调研历史及可选扩展，不以填满21项作为系统目标：

| 层级 | 指标 | 本轮处理 |
|---|---|---|
| 核心：工具选择 | 命令多样度、命令熵、主导工具占比 | 规范化执行程序名可支持；已在标量预实验实现 |
| 核心：动作组织 | 动作切换率、下一步条件熵、最长动作连续段占比、动作二元组合复用率 | 固定动作映射和有序执行事件可支持；未知类别保留位置 |
| 核心：局部重复 | 相邻相同命令名比例 | 只能解释为程序名重复，不是失败重试 |
| 有条件扩展 | 参数数量、选项使用比例 | 仅在 argv/命令行可靠保留且两类覆盖一致时比较 |
| 暂缓 | 管道/条件链、批量提交 | 进程启动记录不等于原始 shell 程序 |
| 暂缓 | 非零反馈后的重试/修订/换工具 | 需要命令完成与反馈配对；execve syscall 返回值不能充当最终程序退出状态 |
| 暂缓 | 资源探索、回访与范围切换 | 需要真实对象访问，argv 中提到资源不等于访问过资源 |
| 暂缓 | 反馈到下一次决策的节奏 | 需要反馈可用与提交时间；进程启动间隔不能命名为思考时间 |

“通用日志”在本轮具体限定为能形成有序可归属执行记录的主机日志。Linux auditd 为当前适配器入口；Sysmon Event 1 和 Windows 4688 作为字段契约参考，未实现或验证 Windows 适配。只有认证信息的日志或普通 syslog 并不自动满足契约。采集配置、会话边界和未知动作覆盖必须核验。

## 调研来源及得到的具体启发

- AIT/AECID 的 Human/Agent 运维日志项目：参考命令词汇、参数与时间的定义，也参考其对聚合时间跨度、事件量混杂的排除。不能直接把聚合 actor 的统计改名为独立会话证据。https://github.com/ait-aecid/llm-user-shell-sim
- Trace：命令/参数与局部组合值得作为对照；模型家族分类不等于 Human/Agent 分类。https://arxiv.org/abs/2605.01186
- ProcGrep：以动作和局部程序模式组织画像；编码动作不能直接称为攻击阶段。https://arxiv.org/abs/2606.16988
- HABITS：采用多行为视角及组消融，避免依赖单一时间特征；其购物任务及模拟 planner 规律不能直接当作攻击场景事实。https://aclanthology.org/2026.realm-1.64.pdf
- 实际日志依据：auditctl/execve 文档、Sysmon 事件说明、Windows 4688 字段说明。Windows 4688 命令行默认可为空，Linux 执行事件也依赖审计规则，因此参数特征未进入跨来源核心。

## 新主稿与后续实验

完整自包含 TeX：`research/paper/human-agent-fingerprint-main.tex`。主稿包括摘要、动机、相关工作、日志契约、8项公式、画像展示、已完成进展、实验设计、局限、结论和参考文献。旧 `research/paper/main.tex` 保留为同题检索旧稿。

已完成的AIT标量预实验使用95次独立路径运行（50 Human、45 Agent）；8项整体统计在任务留出下的BA为52.89%，没有形成可靠区分，词汇基线为93.78%，存在shell初始化与采集差异的可能影响。详见[预实验报告](log-fingerprint-pilot-v1.md)。该结果没有检验时间窗口矩阵或关联收益。

下一步：实现有序窗口的指纹矩阵；固定训练/评估划分、最小证据与拒判规则；按任务、模型和来源检验迁移；比较原关联方法与直接加入矩阵后的结果，并以移除矩阵/维度组做消融。新增1,142条目录记录不自动成为1,142个合格实验样本。

## 数据是否更换：本轮选择

目前核实的候选尚未在本项目中同时通过“安全攻击任务”和“两类统一主机日志”两项要求。采用分工而非直接混合：

| 数据 | 保留/新增用途 | 主实验资格 |
|---|---|---|
| 原 Cyber Task Horizons | 保留原始记录、解析适配、历史对照及探索性安全任务迁移 | Human终端录制与Agent工具调用并不同源；不是唯一确认集 |
| AIT/AECID llm-user-shell-sim | 已审计109份原始运行，95份进入固定标量预实验 | 有Human/AI、audit/syslog等；排障领域，不直接证明攻击识别 |
| CyBiasBench | 可选Agent攻击画像扩展 | HTTP请求序列、无Human组，不用于命令级二分类主实验 |
| 自采匹配安全任务日志 | 少量任务先试采，冻结协议后作为确认实验 | 两类任务、初态、工具、日志契约和会话登记必须可比 |

CTH官方说明：https://github.com/lyptus-research/cyber-task-horizons-data/blob/main/data/human/eval_logs/README.md 。同为`.eval`不等于相同采集机制；去除格式标记不能恢复未记录的执行事件。

AIT官方仓库：https://github.com/ait-aecid/llm-user-shell-sim 。提供`data.zip`及原始`LOGS_Result_<Actor>/expX/`；优先原始每次运行，不把按actor拼接的聚合日志或滑窗作为独立会话。已下载并核验归档，角色、会话和解析审计保存在`research/results/log_fingerprint_pilot_v1/`；预实验结果仍受当前任务和采集条件限制。

CyBiasBench字段：https://github.com/Harry24k/CyBiasBench/blob/main/schema/columns_traces.md 。请求方法、路径和状态码不能改名成程序执行序列。

因此，原数据仍有保留必要；旧同题配对目标、旧分类器与旧效果指标不自动沿用到新主实验。替换确认实验数据不等于丢弃原始资产。
