# 后续实验计划：由错例驱动、允许中途转向的关联研究

## 目标

在不提高外层漏关联率、且各可估计 Human/Agent 分组不退步的前提下，显著降低绝对误合并率。当前同题标签只代表检索相关性，不能证明同一人员、Agent、活动或组织。实验结论只限于同题检索代理任务。

这不是必须按编号走到底的线性路线。v15 任务均衡 IDF、阶段张量画像、任务语义上下文、困难负例排序和开放集拒判是候选方向；错例、数据可用字段和前一项结果决定下一步做什么。若诊断推翻原假设，允许立即换方向，并记录为什么换。

## 失败诊断

- **v10：** 产物包含度救回部分短轨迹，但两组 Human–Agent 同题配对没有共享显著产物；一折漏关联从 2.56% 升至 10.26%。
- **v11：** 低阈值接纳了所有观测到的同题配对，但绝对 FMR 仍为 75.87%。
- **v12–v13：** 困难负例验证器将 FMR 降至约 19%，同时把 FSR 推至约 17%；穷举阈值后仍没有任何内层可行点。
- **v14：** 固定查询内 top-k 在三个外层折都没有可行的内层 k。第一折 k=1 把 FMR 从 54.9% 压到 5.1%，却把 FSR 提至 30.4%；k=9 虽把 FSR 拉回 1.23%，FMR 却升至 87.5%。第二折 k=5 的多项指标改善，但覆盖率从 99.38% 降至 98.15%。第三折 k=5/6 仍触发覆盖率或 Agent–Agent 误合并门槛。问题已不是继续试一个全局阈值就能解决。

## 分批执行

### A. 先做泄漏与数据适配性控制

1. 保持按 `(benchmark, task)` 分组的嵌套外层划分，所有词表、IDF、画像投影与模型仅在外层训练任务拟合。
2. 增加 `task-ID oracle` 作为**标签泄漏上限对照**，明确标注为不可部署、不得算作方法结果。它用于确认“同题”目标本身是否可被任务标签直接读出。
3. 检查原始记录是否含有推理时真实可见的题目上下文或任务说明。若存在，单独做“上下文检索”实验；不得用解析出的 task ID、目录名、答案、目标字符串或同题标签作为输入。若上下文只在标注文件中存在，则不进入主实验。
4. 把每题轨迹数、采集接口、轨迹长度和解析完整度列成数据审计表；同一条轨迹的不同片段必须保持在同一折。

### B. 候选路线：任务均衡的稀有证据表示

**主要改动：** 把命令/操作项的文档频率从“轨迹数”改为“训练任务组数”。一个任务即使有多条轨迹，也只对训练 IDF 贡献一次，避免重复轨迹改变通用命令和稀有产物的权重。只用训练集任务标签建立 IDF；外层测试任务的 task ID 不进入打分。

**预测：** 常见于许多不同题目的 `ls/cat/grep` 等泛化操作权重降低；罕见参数、文件名、路径片段和阶段内操作组合更能区分题目，降低异题误连。

**竞争解释：** 如果同题 Human/Agent 的解题路径差异很大，任务均衡 IDF 会进一步放大特定工具或采集接口差异，反而增加漏关联。

**验收：** 先比较命令基线、v11 全局词频 IDF、任务均衡 IDF；仅当内层选出的阈值同时满足全部硬门槛才进入外层。逐折报告错误率、覆盖率、排序及 H–H/H–A/A–A；不通过即停止该分支。

### C. 候选路线：阶段对齐的 Human/Agent 多维画像

**主要改动：** 将画像由全轨迹均值扩展为“阶段 × 动作族 × 证据通道”张量。通道分别记录命令/工具族、参数与稀有产物、动作转移和局部重复/修复模式；用短轨迹友好的阶段对齐或软序列匹配比较张量，不再只比较全局 24 维统计量。

**跨执行方式：** Human 终端命令和 Agent 工具调用先映射到共享动作语义；另保留来源专属分支。打分使用折外预测的 Human/Agent 概率及其不确定性，真实标签仅用于诊断。接口、字段缺失率、命令条数等采集路径信号作为混杂控制，不作为主体身份特征。

**验收：** 固定 v15 的候选生成与分折，只增加阶段画像；比较命令/局部序列、通用阶段张量、Human/Agent 条件画像和逐分支消融。至少在 H–A 上出现可重复的内层与外层收益，且 H–H 不退步，才保留该分支。

### D. 候选路线：画像条件化的联合排序与开放集拒判

用 v15/v16 固定的证据构造正例与“工具相同、行为相近、任务不同”的困难负例，训练小型成对排序模型。按查询建立软候选概率，再以分数间隔、候选分布和画像不确定性决定是否关联或拒判。阈值与拒判区间只在内层选取，外层检查漏关联、误合并、覆盖率和四项排序；不允许用“选 top-k”隐式把低置信候选全部连上。

### E. 可按证据插入的路线：推理时可见的任务语义

如果原始轨迹在预测时真实包含题目说明、用户请求或任务上下文，单独测试上下文检索，再测试“上下文 + 行为证据”的受控融合。这可能是最快降低“同题代理”误合并的路线，但它回答的是“是否属于同一任务”，不等于证明共同操作者或攻击活动。只有原始推理输入里确实存在的文本才能用；标注文件中的 task ID、目录名、答案、目标字符串和同题标签都禁止进入模型。若字段实际不存在或不可在推理时获得，关闭此路线，不用合成标签补洞。

### F. 可按错例插入的路线：轨迹不变性与多视图增强

针对工具替换、命令重排、轨迹截断、缺失事件和采集接口变化，先做成对的压力测试与不变性分析。若漏关联集中于这些情形，再评估阶段对齐、部分序列匹配、同义动作归一化或按证据通道缺失自适应的融合。合成扰动只作鲁棒性诊断，必须和真实留出任务结果分开报告，不能冒充新实测样本或改善。

## 固定验收和停止条件

- 训练内层选择须同时满足：总体 FSR 不高于同折基线、总体 FMR 严格更低、所有可估计分组错误率不升、平衡准确率/覆盖率/四项排序不降。
- 任一外层折 FSR 上升即判该轮失败；保留失败结果和触发门槛，不回写成改进。
- 通过内层但绝对 FMR 仍高于 20% 时，只称为开发集上的进步，不称可用归因点。95.3% 外部原始工作点继续独立展示。
- 当前 40 个任务组已反复用于开发，只用于筛选；在同一队列上停止调参后，新增独立任务组做一次性确认。
- 当前每任务一条 Agent 轨迹，不能估计 Agent→Agent 漏关联。下一批数据必须加入多个 Agent 模型、重复运行和稳定主体 ID；若目标是攻击者/组织归因，还需真实主体或活动级标签。

## 自适应决策：先定位问题，再选路线

每一轮开跑前，先从逐对预测和错误轨迹判断主要失效属于哪类，再挑一个最能区分原因的实验；**不要求所有方向都做，也不要求编号顺序**。

| 错例/数据证据 | 优先尝试的方向 | 若结果不支持假设 |
|---|---|---|
| 同题两侧共享少量、但较独特的参数或产物，泛化工具占分过高 | 任务均衡 IDF、稀有字段权重、字段级负证据 | 回看解析完整度、跨来源字段映射；若稀有项也是任务模板泄漏，则弃用 |
| 正例证据存在，但出现在不同阶段或顺序变化后 | 部分序列对齐、软阶段匹配、动作转移图 | 若正例和负例同样相似，转向上下文或更强的区分性视图，不继续调序列窗口 |
| Human–Agent 错误显著高于同来源错误，且接口字段差异与判定相关 | 共享动作语义 + 来源条件分支；采集格式作为混杂变量审计 | 若跨来源差异来自真实行为而非格式，保留来源条件结果并扩大配对数据 |
| 相似工具/行为的异题负例占主导 | 困难负例、负证据、对比排序、分数间隔与拒判 | 若拒判只靠牺牲覆盖才能降 FMR，报告选择性风险曲线，不称总体改进 |
| 原始输入中真实包含同题上下文 | 独立的上下文检索与行为融合对照 | 若上下文不适用于目标场景，主方法回到行为证据；明确这是不同任务定义 |
| 同一主体跨任务应关联，却被当前“异题即负例”标签记成负例；或正例本来只想测同题 | 先重定关联目标与标注：同题检索、操作者、Agent 实例、活动/组织是不同标签 | 暂停对应归因结论，补充相应真值数据，不继续对错标签优化 |
| 多种方法在开发集都只有窄阈值好点，或不同折方向相反 | 查任务组数、正负构成、置信区间、采集偏差和外部域差异；考虑当前数据集不适配 | 改数据采集/任务定义，或将结论限定为排序/候选缩减，不强行追求分类点 |

探索阶段允许根据结果改方向；为避免“追着测试集调参”，每次变向需写明触发的错例证据、竞争解释和新一轮的单一主要改动。外层折只作轮次审计；多轮后不再把它当未见验证集。所有有希望的分支最终都要用新任务组一次性确认。指标门槛用于拒绝退步，不用于挑选更好看的子组或隐藏绝对错误率；若数据支持不了“所有指标都改善”，如实给出 Pareto 取舍并继续找原因。
