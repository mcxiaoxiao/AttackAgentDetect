# 多维轨迹画像与关联：扩展基准实验 v2（联合指标选择）

日期：2026-10-31。状态：评估规则已冻结；嵌套开发评估与一次性锁定外部评估已完成。

## 预注册修订记录

在新扩展基准的关联指标尚未计算前，根据研究目标将方法与阈值选择由“优先最低 FMR”修订为多指标联合选择，并将联合效用的外部配对区间纳入有效性判据。修订不改变数据队列、特征、候选方法、锁定外部集、误差定义或外部评估流程。先前已公开的 177 条开发队列结果属于探索性背景，不作为本轮外部证据。

修订动机来自既有开发集案例目录：在先前冻结的 20\% 操作点，Human 查询到 Agent 候选的逐对清单中，加入模式相似度后有 208 条跨任务链接被引入、7 条被移除；同题漏关联中有 37 条被恢复、72 条仍未解决。这些是非加权、定向配对计数，不能当作总体错误率或独立验证。它提示模式信息能找回部分同题结果，也可能把“同为 Agent/Human”误当作身份连续性，因此本轮画像分数只用标签无关的行为证据；选择规则同时顾及多类错误与排序，避免只奖励某一项。

## 研究问题

检验分阶段、分动作、分通道的轨迹画像，以及局部序列匹配，能否减少误合并，同时把漏关联控制在可接受范围。主要分析对象是同一公开任务上的轨迹检索；Human/Agent 标签仅用于结果分层，不作为关联模型的输入。

## 基线与数据

- 未多维 TeX 基线：标签 `baseline/single-mode-association-20261030`，提交 `cdaa1a1d878a066d31975ecb9cdb5a4f1bae578c`。归档目录已按字节核对，37 个 TeX 与图件文件均与标签一致；不得覆盖。
- 数据：Cyber Task Horizons 固定提交 `178c0da1800f9c07311e1b8d6c61dd8104e7b4ae`，CC BY 4.0。收集七套基准中已公开的 Human 终端轨迹，并为每套基准固定使用 Claude Sonnet 4.6 对应的公开模型评估集。下载清单、LFS 哈希、解析脚本和输入哈希单独保存。
- 开发数据：InterCode-CTF、CyBench、NYUCTF。这些任务已用于先前的探索；只在此部分进行训练折内候选选择。
- 锁定外部数据：CVEBench、CyBashBench、CyberGym、NL2Bash。先做格式与任务重叠审计，不用外部标签筛特征、阈值或模型。若某基准没有足够的 Human/Agent 同题记录，按预定规则排除该基准并记录原因。
- 题目键只用于配对和评估：去掉 ID 中最后一个 `/` 之前的路径前缀；CVEBench 再去掉公开任务后缀 `-one_day`。只在同一基准内配对。主外部汇总要求每个基准至少有 3 个 Human/Agent 同题任务组；不足者单独报告，不进入主汇总。
- 分析单位是 `(benchmark, task)`。同题标签表示任务匹配，不表示操作者、攻击者或组织相同。原始命令、提示词和输出不进入导出结果。

在读取任何性能结果前完成了队列与采集格式审计。实际有可配对执行轨迹的外部基准为 CVEBench（10 个同题组）和 CyberGym（4 个同题组）。所选 CyBashBench（200 条）与 NL2Bash（129 条）Agent 评估集保存的是提示与最终文本答案，没有 bash 工具调用事件；因此不能把模型生成答案当作已执行轨迹，两者按既定门槛排除在主外部汇总外，并保留在队列审计中。故本轮主外部结果覆盖 2 个基准、14 个同题组，结论不外推到另外两套无执行日志的基准。

## 固定方法与选择规则

先生成对齐的命令名与动作序列，再比较六种固定方法：1–2 gram、sublinear TF-IDF 命令相似度；24 维统计画像；4×8×3 阶段张量的展平表示；Tucker/HOSVD 投影（秩 2×4×2）；IDF 加权命令与有序二元组部分覆盖；以及训练折内拟合的融合分类器。画像与张量用训练中位数补缺、训练均值方差标准化，并以 `exp(-平均绝对差)` 形成相似度。融合为 C=0.5、类别平衡的逻辑回归，训练对按任务标签平衡采样。向量器、缺失值、标准化、张量因子、分类器和阈值都只在训练任务拟合。

开发集采用按基准分层、按任务分组的三折嵌套评估。每种方法在训练侧以 101 个分位阈值搜索，在宏平均 FSR 不超过 20% 的条件下，最大化 8 项误合并/漏关联率、平衡准确率和查询覆盖率的平均方向调整效用；并列时依次取更低 FMR、更高阈值。方法选择先保留 14 项预先列明指标（8 项错误率、平衡准确率、查询覆盖率及 4 项排序指标）中的 Pareto 非支配方法，再取相对命令 TF-IDF 基线的平均方向调整变化最大者；并列时依次取更少退化指标、更低 FMR、更高 NDCG@5、结构更简单的方法。无法观测的指标标为缺失并从联合效用中排除，不填作改善。外部评估使用开发任务训练所得的冻结方法与阈值，不对锁定基准回调参数。部分覆盖分数固定为 IDF 加权命令重合与有序二元操作重合各占 0.5。

## 指标与成功判据

主指标是锁定外部基准上的总体 FMR 差值，按基准内任务等权、基准等权汇总；FSR 是护栏。同步报告 H–A / 同模式 FSR、FMR、平衡准确率、覆盖率、Hit@1、MRR、Recall@5、NDCG@5，以及每个基准结果。

完整报告 14 项指标的方向调整配对差值和 95% 区间，并统计点估计改善、持平、退化的指标数。另按任务计算可用指标的平均方向调整配对变化，并按基准分层、在任务组上配对 bootstrap。只有当外部区间同时支持 FMR 下降、联合多指标效用改善，FSR 差值上界不超过 +2 个百分点，且排序指标没有明确退化，才称其满足预设有效性标准；联合选择分数不能替代逐项结果，也不能据此声称所有指标都显著改善。各项指标区间均为 5,000 次任务簇配对 bootstrap。

## 偏差控制与停止规则

- 旧 40 任务不再作为新证据；四个新基准是一次性外部检验。
- 不按显著性反复试阈值或删除任务。候选集、训练目标、外部数据范围和停止条件固定后执行。
- 若外部结果没有达到预设判据，保留所有结果并停止在该队列上调参；下一轮先取得新任务或同接口配对轨迹，再预注册独立验证。
- Human 终端输入和 Agent 工具调用来自不同采集接口；结果只能解释为这些公开轨迹中的任务检索表现，不能解释为真实攻击者或组织归因。
- 原始 `.eval` 文件保留在 git 忽略的数据目录；实验输出只含去身份化轨迹 ID、命令类别/名称特征、分数与汇总指标。

## 冻结外部结果（一次性评估）

外部结果已由 `results/multidimensional_rerun_v1/results.json` 生成并锁定；没有用外部数据回调特征、阈值或方法。完整逐任务、逐方法分数与图件见同目录结果文件，以及 `results/figures/multidimensional-rerun-v1.pdf`。网页与论文分别汇报精简结果和完整指标表。

- 联合开发集选择器选中 IDF 加权局部序列重合，方向调整后的开发集联合均值变化为 +1.64 个百分点。嵌套三折的外层选择却三次都选了命令 TF–IDF 基线，显示小开发集上的方法选择不稳定；因此入选方法应视为待验证方案，而非稳定赢家。
- 锁定外部集为 14 个任务组、两个基准（CVEBench 10、CyberGym 4）。CyBashBench（200 条 Agent 记录）与 NL2Bash（129 条）所选模型记录没有可观测执行命令，按预先的格式门槛排除。外推范围仅限具有配对执行轨迹的这两个基准。
- 对照命令 TF–IDF 基线，方向校正后 13 项可估指标中 8 项点估计改善、5 项持平、0 项退化；Agent–Agent 漏关联无法估计。任务簇联合效用为 +5.14 个百分点，95% 区间 [+0.74,+8.15]。满足预设的相对有效性判据，但这不表示每项指标各自显著，也不表示所有个体匹配可靠。
- 总体误合并率从 100.0% 降到 95.3%，配对差 −4.7 个百分点（95% 区间 [−7.2,−2.2]）；总体漏关联率维持 0.0%。平衡准确率从 50.0% 到 52.3%。Hit@1 与 MRR 点估计提高，Recall@5 与 NDCG@5 的区间跨零。总体查询覆盖 100% 反映接受阈值下总能给出候选，不代表候选可靠。
- 绝对误合并率仍为 95.3%，平衡准确率仅 52.3%；本轮只能说明小型、任务内检索代理上的相对变化，不能据此自动关联身份、人员、攻击者或组织。
- 24 维画像与 4×8×3 张量特征均保存为独立记录，但它们没有被联合目标选中。当前入选的是命令名与有序二元组的 IDF 局部重合；因此结果不构成张量画像优于基线的证据。

主外部指标的完整配对区间、按基准结果、队列审计、程序和图件均随提交保存。原始命令轨迹未导出到公开结果。
