研究

当 AI Agent 参与攻击时，如何判断两条日志是否属于同一任务？本研究提供可复现的评估方法，探索执行方式与行为证据的结合，支持跨事件安全分析。

  1. 执行方式对轨迹匹配的影响测试加入执行方式信息后，轨迹匹配准确率是否提升。当前研究 · 177 条轨迹 · 更新于 2026-10-30
  2. 基于日志的 Human / Agent 识别比较命令与动作特征对执行方式分类的效果。方法与结果 · 更新于 2026-10-30
  3. 多维行为画像与轨迹关联分析阶段、操作与行为通道如何影响误合并与漏关联。锁定外部实验 · 14 个任务组 · 更新于 2026-10-31
  4. 判别式配对分类（v15）探索性结果：误合并率（FMR）↓77%，平衡准确率（BA）↑55%，顶部命中率（Hit@1）↑207%，NDCG@5↑79%。探索性开发 · 97 条轨迹 · 更新于 2026-10-31
  5. 增强型判别式分类（v16）Gradient Boosting + FSR 惩罚：本开发队列的漏关联率（FSR）降至 0%，Hit@1、MRR、NDCG@5 均达到 100%。探索性结果 · 97 条轨迹 · 更新于 2026-10-31
  6. CTF 行为轨迹集可追溯来源的整理子集：97 条轨迹、40 个任务组、1,558 条外层评估配对。数据集与来源 · 更新于 2026-11-01
  7. 同源遥测下的 Human、Script 与 Agent 对照在统一任务与日志采集条件下比较不同执行方式。计划 · 更新于 2026-10-30
  8. 跨日志源与攻击场景的迁移验证在不同遥测来源与带标注的攻击轨迹上评估行为画像。计划 · 更新于 2026-10-30
