研究

AI 正在改变网络攻击的组织与执行方式。本研究探索如何将执行主体与行为过程纳入统一的攻击活动表征，并评估这类证据在跨事件安全分析中的作用。

  1. 执行方式如何影响行为关联检验执行方式信息是否改变公开 CTF 任务中的轨迹匹配。当前研究 · 177 条轨迹 · 更新于 2026-10-30
  2. 基于日志的 Human / Agent 识别比较命令与动作特征对执行方式识别的作用。方法与结果 · 更新于 2026-10-30
  3. 多维行为画像与轨迹关联分析阶段、操作与行为通道如何改变误合并与漏关联。画像研究 · 更新于 2026-10-30
  4. 同源遥测下的 Human、Script 与 Agent 对照在统一任务与日志采集条件下比较不同执行方式。计划 · 更新于 2026-10-30
  5. 跨日志源与攻击场景的迁移验证在不同遥测来源与带标注的攻击轨迹上评估行为画像。计划 · 更新于 2026-10-30
