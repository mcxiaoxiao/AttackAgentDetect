数据集概览

V16测试套件包含1558个查询-候选对，来自40个CTF任务组的97条独立执行轨迹。每个配对都有真实标签（同任务vs.异任务），并使用balanced_selected方法和discriminative pair scoring进行评估。

数据来源

轨迹来自三个公开CTF基准：CyBench、InterCode-CTF和NYU-CTF。人类轨迹来自终端输入日志；Agent轨迹来自工具调用记录。same_task标签表示两条轨迹是否解决同一道CTF题目。

评估协议

我们使用嵌套交叉验证，3个外部fold和3个内部fold。外部fold是任务留出的：测试任务在训练中从未见过。指标在任务组级别计算，带有95% bootstrap置信区间。

快速开始

# Clone the repository git clone https://github.com/mcxiaoxiao/AttackAgentDetect.git cd AttackAgentDetect # Install dependencies pip install -r requirements.txt # Run V16 evaluation python experiments/balanced_innovation_v16/run.py # Results will be saved to results/balanced_innovation_v16/

关键指标

V16实现完美误拆分率（0%）和强准确率（81.1%），同时控制误合并率（18.9%）。带有FSR感知优化的Gradient Boosting分类器消除了所有误拆分，同时保持显著的误合并降低。

方向性错误分析

错误率按查询-候选模式对分解。V16在所有子组（H→H、H→A、A→H）中实现0% FSR，FMR集中在H→A和A→H跨模式对中。

可复现性

所有结果完全可复现。实验使用固定随机种子（SEED=42）和确定性算法。在相同数据上运行相同脚本将产生相同结果。

计算需求

V16实验在标准笔记本电脑（8核CPU，16GB内存）上约45分钟完成。每个指标5000次bootstrap抽取的嵌套交叉验证是主要计算成本。
