研究目标


测量人工、脚本与 Agent 执行对攻击活动关联的影响。当前公开实验只有人类操作记录与模型 Agent 工具调用，暂无匹配的脚本执行样本。





范围

研究活动关联，不做组织归因。公开数据没有攻击者或 campaign 同源标签。

方法工作证据与边界



日志关联综述System log correlation (JISA 2025)62 篇论文，26 种工具回顾用于网络攻击检测和预测的日志关联方法，并指出虚假相关、缺失数据与阈值设置等可靠性问题。


关联综述Security event correlation (IEEE Access 2022)系统综述，127 篇覆盖安全事件关联系统，归纳相似度、步骤式和混合方法，并整理数据集与评估指标；说明事件关联是成熟研究方向。


跨主机关联Ostinato (2023)行为图相似度比较带 TTP 标签的主机溯源图，在 500 台主机的红队场景中扩展攻击活动；未按人、脚本或 Agent 执行方式分层。


因果关联HOLMES · IEEE S&P 2019审计日志与信息流将多主机审计行为与信息流组合为 campaign 信号；公开评估未报告执行方式标签。


跨主机关联SteinerLog · ASIA CCS 2022告警因果图用因果分析和层级图遍历关联企业内的攻击活动；摘要未提供执行方式对照。


日志关联SFM · arXiv 2024日志到 ATT&CK / campaign从审计日志映射技术并关联已知 campaign；邻近活动关联问题，但没有参与方式标签。


APT 行为综述APT detection review · Journal of Cybersecurity 202445 项研究，行为相似与因果关联归纳 APT 检测中的相似度、因果、结构和案例方法；覆盖的不全是跨活动身份关联。


告警序列HMM alert correlation · IEEE Access 2019IP、主机、时间窗与合成告警先按告警属性和时间窗聚类，再用 HMM 推断 APT 阶段；结果来自合成数据，不是细粒度主机行为相似度评估。












攻击故事与情报匹配单次攻击路径重建、CTI 到日志匹配4 项



这些工作重建一次攻击内部的路径，或将威胁情报图匹配到审计记录；与活动关联相邻，但不判断操作者。






方法工作证据与边界



攻击故事SLEUTH · USENIX Security 2017溯源图压缩从审计事件依赖图压缩并重建攻击活动；解决图内攻击故事重建，不标识操作者。


攻击故事HERCULE · ACSAC 2016加权日志图以社区发现从异构日志中重建多阶段攻击；展示行为关联的实际用途，不含执行方式标签。


日志关联POIROT · ACM CCS 2019CTI 图 ↔ 来源图将威胁情报中的攻击图与审计日志来源图对齐，用于已知攻击活动搜寻；不比较人类与 Agent 执行。


攻击故事ATLAS · USENIX Security 2021因果与语义序列从系统审计日志恢复攻击故事；关注活动内部的因果重建，不判断操作者类别。












执行者识别与轨迹表示Human、Agent、模型指纹与操作轨迹8 项



包含直接区分人类与 Agent、推断 Agent 模型身份或比较操作轨迹；采集方式和研究目标差异较大。






方法工作证据与边界



日志识别AIT / AECID · 2026预印研究 / 论文审稿中用 Linux audit、syslog 和应用日志区分人类与 LLM 运维 Agent；与“从日志识别参与方式”最直接相邻，但不是攻击场景，无脚本组或活动关联评测。


行为识别HABITS · REALM 2026人类与购物 Agent 会话区分把多类弱行为信号汇总为 session 特征；同类强分类器表现相近，贡献主要在行为视角。不同于攻击主机遥测，也不测攻击活动关联。


浏览器识别Agent detection · 2026浏览器自动化轨迹区分 Human / Bot / Agent；主要判别信号来自 Playwright 输入事件缺失。说明三分类很重要，但该指纹依赖浏览器遥测。


威胁分析OHAI · CMU SEI 2025框架与公开案例提出人类 / AI 威胁归因的分析流程；已有工作先例意味着不能把“区分人和 AI”单独作为新颖性。


攻击轨迹指纹Trace · 2026终端命令序列识别攻击 Agent 的模型家族，并探索防御性提示注入；识别的是“哪个模型”，不是“人 / 脚本 / Agent”。


主动模型指纹LIDAR · 2026主动探针 + 概率识别器利用 Agent 的验证、失败恢复等行为识别底层模型；需要主动探针与干净参考，问题目标不同。


主动模型指纹AgentTrace · 2026执行级序列诱发工具接口失败，分析后续修复序列识别模型；不是被动防守侧日志分类。


轨迹表示ProcGrep · 2026程序化行为表示将动作序列编码为程序频率分布并计算 JSD；可借鉴轨迹比较，论文任务是编码 Agent 工作流，不是攻击同源性。












生成内容检测方法类比概率特征、分类器与跨域评估6 项



可参考概率评分、轻量分类和域外测试设计；这些研究输入是文本，不是主机审计事件。






方法工作证据与边界



文本检测类比DetectGPT · ICML 2023模型 log-prob比较原文与扰动文本在语言模型概率下的差异；启发评分设计，但日志不是自然语言生成文本。


文本检测类比Fast-DetectGPT · ICLR 2024条件概率曲率以代理模型概率评分做高效零样本文本检测；可借鉴概率特征，但结构化系统事件没有自然语言 token 概率。


文本检测类比Ghostbuster · NAACL 2024辅助模型特征 + 分类器从弱语言模型的 token 概率构造固定特征后监督分类；可借鉴固定特征和线性基线，仍需有标签训练数据。


文本检测类比Binoculars · ICML 2024双模型困惑度用两个预训练模型的困惑度与交叉困惑度检出生成文本；不依赖生成模型 logits，但仍需语言模型概率。


泛化评估MAGE · ACL 2024跨任务 / 模型 / 提示用多任务、多模型文本检测设置评估域外泛化；可借鉴分组留出，数据不是命令或主机日志。


鲁棒性评估RAID · ACL 2024多模型文本基准跨生成模型、领域和改写攻击测文本检测鲁棒性；借鉴分组留出与压力测试，数据不是执行日志。












APT 组织级关联威胁情报与恶意软件行为模式1 项



该工作推断组织之间的关系，标签和分析对象在组织层，不等同于日志级活动关联。






方法工作证据与边界



组织关联APT group behavior patterns · Electronics 2024粗糙集 + 威胁情报用恶意软件和威胁情报中的行为特征建模组织间关联；输入与目标是组级情报，不是统一传感器下的活动日志匹配，公开关系标签也未经独立真值裁定。













相关研究会用行为相似、攻击步骤和因果关系连接日志与活动；现有公开评估未按人、脚本、Agent 执行方式比较关联错误。下一步是在统一遥测和活动标签下检验这类差异，而不是预设方法已经失效。
