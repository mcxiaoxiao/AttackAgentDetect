基于行为证据的轨迹关联

在 40 个公开 CTF 任务组的 97 条轨迹上评估配对分数。相同题目仅作为检索标签。

方法

配对分数由命令 TF–IDF 相似度（45%）和短轨迹中产物名称的 IDF 加权包含度（55%）组成。两条轨迹共享显著产物时，这种计算可减弱长轨迹中无关命令带来的稀释。每个外层任务留出折的阈值都只依据内层训练任务，并按预设错误约束选择。

评估结果

在这批数据上，结合命令与产物证据后，两类错误率点估计均下降，首位命中率提高。但 75.87% 的误合并率仍然过高，不能用于攻击归因。

变化为配对任务簇估计及 95% 区间。命令与产物方法接纳了 148 条观测到的同题配对，40 个正例任务组中未观测到漏关联事件。若把任务组视为独立簇，0/40 对“出现任一漏关联的任务组比例”给出的单侧 95% 上限为 7.2%；这不是任务宏平均漏关联率的置信区间。

研究局限与数据选择

我们选择 Cyber Task Horizons 子集，是因为它公开提供了任务重叠的 Human 与 Agent 轨迹，许可允许复用，题目 ID 也可复现。这使我们能够用两类轨迹评估同题检索，同时将结论限定在现有标签所能支持的范围内。

因此，本评估回答的是一个较窄的问题：行为分数能否检索到来自同一道 CTF 题的轨迹；它不能证明轨迹属于同一人员、Agent、活动、主机或真实攻击。Human 记录采自终端输入，Agent 记录采自结构化工具调用，执行方式与采集接口相互混杂。任务组此前已用于方法开发，外层留出结果不是独立外部确认；75.87% 的误合并率也意味着多数异题配对仍被连在一起。

指标写法：FMR（误合并率）；FSR（漏关联率 / 误拆分率）；BA（平衡准确率）；Hit@1（顶部命中率）。
