基于行为证据的轨迹关联

在 40 个公开 CTF 任务组的 97 条轨迹上评估配对分数。相同题目仅作为检索标签。

方法

配对分数由命令 TF–IDF 相似度（45%）和短轨迹中产物名称的 IDF 加权包含度（55%）组成。两条轨迹共享显著产物时，这种计算可减弱长轨迹中无关命令带来的稀释。每个外层任务留出折的阈值都只依据内层训练任务，并按预设错误约束选择。

评估结果

在这批数据上，结合命令与产物证据后，两类错误率点估计均下降，首位命中率提高。但 75.87% 的误合并率仍然过高，不能用于攻击归因。

研究局限与数据选择

公开数据难以同时提供可对照的 Human 与 Agent 行为、可复现的任务标签和经独立核验的攻击活动真值。受数据可得性限制，我们采用 Cyber Task Horizons 中题目重叠的 Human 与 Agent 轨迹，并将共享题目身份作为任务层面的关联代理标签。CTF 题目为两条轨迹提供共同目标与任务上下文；InterCode 将 CTF 解题描述为包含环境探索、调试和利用的迭代过程。相关案例关联工作也说明了行为上下文的价值：ATLAS（USENIX Security 2021）从因果审计图中的行为序列恢复攻击故事，HOLMES（IEEE S&P 2019）则将可疑信息流关联为 campaign 级图。这些工作为基于行为的关联提供研究动机，但依赖攻击特定证据，并不意味着共享题目身份就等同于共享活动。因此，我们将任务层面检索作为初步检验，评估行为证据能否连接 AI 与人类轨迹，而不据此归因共同操作者或 campaign。（InterCode，NeurIPS 2023） · ATLAS（USENIX Security 2021） · HOLMES（IEEE S&P 2019）

评估显示出有用但尚不充分的信号：命令与产物排序将 Hit@1 从 29.60% 提升到 79.31%，但 75.87% 的误合并率仍然很高。正例只表示两条轨迹来自同一道基准题目，不能证明它们属于同一人员、Agent、活动、主机或真实攻击。Human 记录来自终端采集，Agent 记录来自结构化工具调用，执行方式与采集接口相互混杂。由于这些任务组也参与了方法开发，外层留出结果不是独立外部确认。因此，结果支持继续研究 AI 与人类轨迹检索的可用性，不支持实际攻击归因。

指标写法：FMR（误合并率）；FSR（漏关联率 / 误拆分率）；BA（平衡准确率）；Hit@1（顶部命中率）。
