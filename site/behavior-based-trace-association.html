为什么引入行为指纹

部分轨迹关联方法把工具选择、操作顺序等行为相似性作为关联线索。Agent 参与后，模型、框架、提示和工具配置也会影响操作：不同任务可能呈现相似行为，同一任务由人和 Agent 执行时也可能形成不同路径。我们检验这些差异是否改变误合并与漏关联。

在 CTH 的受控同题代理实验中，Agent 角色占比越高，固定阈值接受的关联越少：误合并下降，但漏掉的同题关联增加，最终 BA 下降。这提示执行组成会改变相似度与判定阈值的对应关系，也构成将行为指纹直接纳入关联打分的动机。

模型身份识别通常围绕已标注或已登记的候选系统建立参考，部分方法还需要主动探针。我们的关联模型直接使用留存轨迹之间的行为差异，推断时无需先判定具体模型或 Agent 产品；训练仍需关联标签与兼容的日志字段。

在具体评估中，相似度先为候选轨迹排序，再由工作阈值决定是否接受关联。排序质量与误关联率分开报告。

可变长度的三块行为指纹

将轨迹切成短窗口，每一行记录局部行为（B）、顺序演化（S）；只有日志含真实事件时间时，才计算执行节奏（T）。

02轨迹配对证据

矩阵形状与窗口

每窗 8 个事件；B＋S 为 J × 16，有实际时间字段时为 J × 24。J 随轨迹长度变化，不再要求整条轨迹至少 16 条命令；CTH 配比实验接受至少 2 个事件的有效窗口，其他适配器按各自预先声明的最低长度处理。实验最多使用前 128 个事件。

定长识别摘要对每个特征计算均值、总体标准差及窗口位置趋势：B＋S 共 48 项，B＋S＋T 共 72 项；这与旧的 24 项整段画像不同。

时间特征按真实观测定义

AIT 提供 audit 事件启动时间，Honey 提供执行耗时而非命令间启动间隔。CTH、Antieval、KYPO 与 CyBiasBench 的关联视图没有可比较的精细事件时间，因此主关联模型使用 B／S；T 在 AIT 执行方式识别与 Honey 耗时对照中单独检验。

指纹怎样参与关联分数

指纹如何改善关联判断

从精确配比、条件化关联、逐块消融到来源迁移，分别检验行为指纹的作用。

精确配比：原有关联基线如何变化

沿用原 CTH 17 题队列，每次从中轮换使用 16 题，共 32 个查询／候选角色，并在 170 次配对抽样中精确设置五档 Agent 比例。原训练侧阈值下，命令基线 BA 从 53.6% 降至 46.5%，动作二元组从 57.4% 降至 46.5%；端点变化分别为 −7.10 个百分点 [−15.45, +0.06] 与 −10.92 个百分点 [−20.61, −3.06]。

在同一训练侧阈值下，系统更少接受关联：异题误合并减少，同题漏关联增加。这里观察到的是工作点随角色组成变化；任务差异和采集方式尚未与执行方式作因果分离。

条件化指纹提升留出关联表现

在相同浅层树和候选集上，命令条件化 B／S 将 CTH 任务留出的 BA 从 65.07% 提高到 68.00%，KYPO 参与者留出从 55.83% 提高到 60.08%；Antieval 从 70.24% 到 70.38%。窗口和树深度由训练侧选择，结果对应训练侧阈值下的同题关联判断。

整来源留出的 CTH 中，BA 提高 4.71 个百分点：FSR 从 85.8% 降至 72.9%，FMR 从 10.3% 升至 13.7%。同一协议下 Antieval 的 BA 下降 3.27 个百分点。完整迁移表展示各来源的增量及适用条件。

有边界的方法优化：比较指纹如何进入分数

固定 40 题图库，以三折内层任务验证选择正则强度，比较标量融合、条件化交互、48 项分量距离与局部 masked DTW。嵌套方法选择器的 Hit@1 为 33.35%（Δ −0.29 个百分点 [−5.67, +5.21]），标量融合为 34.19%；交叉拟合的执行方式辅助分支分别为 30.52% 和 31.15%。完整尝试列入论文附录，当前收益集中在错误取舍和时间信号。

已有命令与产物关联基线

保留的旧基线含 97 条轨迹、40 个任务组和 1,558 条配对。加入显著产物后，Hit@1 从 29.60% 升至 79.31%，任务宏 BA 从 57.35% 升至 62.06%，但 FMR 仍为 75.87%。这是原命令／产物比较，不是 B／S／T 指纹结果。

多来源评估：SSH、HTTP 与 Human 任务检索

Honey for the Agent 提供 9 个模型快照、49 个提示／轮数／环境条件下的 13,080 条合格会话。加入 B＋S 后，条件簇 Hit@1 下降 1.30 个百分点（95% 区间 −2.21 至 −0.35）。在 B＋S 上加入实际命令执行／往返耗时后，变化为 −0.35 个百分点（−0.87 至 +0.16）；这些时间不是命令间隔。

CyBiasBench 提供 450 场指定攻击家族会话、258,019 条 HTTP 请求、5 个 Agent 系统和 3 个目标。留一目标时，路由序列 Hit@1 从 39.02% 到 39.94%（目标均值 +0.92 个百分点）；FMR 从 13.6% 降到 2.8%，FSR 从 74.7% 升到 92.8%。三个目标上的结果分别列入跨来源评估表。

KYPO 增加了参与者留出的 Human-only 对照：97 名参与者、8 个任务层级的 190 个查询中，命令 Hit@1 为 31.71%，命令＋B／S 为 30.29%。跨来源表统一列出规模、观测条件、留出对象和配对效果。

数据、标签与结果能支持的结论

现有证据表明，执行组成会改变任务关联中的错误取舍，可解释的 B／S 特征能改善部分留出条件下的 BA。兼容日志可以直接构造画像并参与配对，无需先登记具体执行系统的身份；实际增益仍取决于来源与关系标签。

关联证据范围

当前评估的关联限于公开基准标签下的同题轨迹检索与配对判断。受数据可得性限制，尚无独立核验的真实攻击活动、campaign 和共同操作者关系标签，因此尚未验证对这些关系的关联效果。

采集路径

CTH Human 轨迹来自终端采集，Agent 轨迹来自结构化工具调用，因此执行方式与接口、仪器采集相互混杂。

验证状态

这些公开任务组参与过方法开发，外层留出用于探索，不等于独立外部确认。另一种更宽训练池的配比实验没有出现单调下降，指纹增量区间均跨零；本页趋势应限定在当前实验设置下理解。
