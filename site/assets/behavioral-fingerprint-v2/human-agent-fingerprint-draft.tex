\large A Matched Evaluation of Behavioral Fingerprints}

\begin{abstract}
We study how AI-Agent participation changes errors in linking traces from the same benchmark task. Cyber Task Horizons (CTH) provides Human and Agent traces from capture-the-flag (CTF) challenges. Across 17 CTH tasks, raising the Agent share from 0\% to 100\% lowers the action-bigram baseline's balanced accuracy (BA) by 10.92 percentage points as missed links rise and false merges fall. The five-share mean BA changes from adding local behavior and sequence features (B/S) are uncertain for all three classifiers. In a frozen external evaluation of 160 NYU D-CIPHER Agent-only challenge groups, B/S raises BA by 5.71 points for XGBoost (95\% paired interval [3.63, 7.73]) and 3.64 points for the decision tree ([1.97, 5.37]). Both models miss fewer same-challenge links and falsely merge more different-challenge pairs. For XGBoost, these error rates change by $-26.10$ and $+14.67$ points, respectively. SVM loses 8.23 points of BA on the same pairs. On 109 AIT troubleshooting runs, the association gain from observed timing (T) remains uncertain.
\end{abstract}

\section{Introduction}
Security investigations must decide which retained traces deserve joint inspection. Event-correlation systems use temporal, causal, provenance, or technique-level evidence to connect records into incident narratives~\cite{holmes,poirot,atlas,ostinato}. Many available traces, however, expose only commands, coarse actions, and sometimes timestamps. We use Cyber Task Horizons (CTH) to compare Human and Agent traces within and across capture-the-flag (CTF) challenges.

Figure~\ref{fig:architecture} traces the analysis from observable logs to a windowed fingerprint and two readouts. The pairwise readout uses fingerprints directly as association evidence. The execution-mode readout estimates the recorded Human/Agent label in a separate evaluation.

The pairwise readout has two distinct errors. A \emph{false split} rejects two traces from the same benchmark task. A \emph{false merge} accepts traces from different tasks. We first ask how these errors vary as the share of Agent roles rises from zero to one. We then compare the same models and candidate pairs with and without the fingerprint. The relation label is benchmark task identity, used as a retrieval proxy.

The exact-mixture experiment measures how errors from a fixed similarity threshold change across role allocations. The matched CTH experiment estimates the B/S increment on identical pairs for three learners, and AIT supplies observed launch times for the timing ablation. In the frozen NYU D-CIPHER evaluation, B/S raises BA for XGBoost and the decision tree by recovering more same-challenge links while accepting more different-challenge pairs. SVM loses BA on the same NYU pairs.

Our contributions are: (1) a coupled five-share mixture test that reports false merges and missed links separately; (2) a matched, three-classifier comparison and B/S/T ablation tests across CTH and AIT; and (3) a one-shot, cross-source Agent-only confirmation with explicit error transitions. We state what each task-proxy label permits and retain both unfavorable and uncertain results.

\section{Related work}
Attack-correlation methods align event, provenance, and technique evidence to reconstruct or search for attack behavior~\cite{holmes,poirot,atlas,ostinato,sfm}. Agent-trajectory work instead studies workflow representation or identification: Trace analyzes terminal behavior, LIDAR enrolls model--harness fingerprints, Known By Their Actions studies browser-agent traces, and ProcGrep treats coding trajectories as programs~\cite{trace,lidar,known,procgrep}. These tasks motivate log-derived behavioral features, but model identity and same-task trace association are different prediction targets. Cross-Agent studies campaign linking with synthetic labels~\cite{crossagent}; those labels also differ from the benchmark-task proxy used here. The appendix reports supplementary association results with their source-specific protocols.

\section{Representation and association model}
Let $x$ and $y$ be two traces, and let $z=1$ indicate that they share a benchmark task. The base evidence $E(x,y)$ contains command TF--IDF cosine and action-bigram TF--IDF cosine. Each trace also receives a windowed fingerprint: B summarizes local action organization and repetition; S summarizes novelty, revisits, and fragment reuse; T summarizes measured launch gaps or durations only when the source records the required time fields. Missing observations remain missing. No time value is inferred from event order or a workflow label.

Figure~\ref{fig:bst-dimensions} defines the eight measurements in each block. With $J$ windows, the trace matrix has shape $J\times16$ for B/S and $J\times24$ for B/S/T. The fixed-length readout summarizes each feature column by its mean and standard deviation, with an across-window trend when selected in training. Figure~\ref{fig:matrix} shows measured AIT windows.

For each available block, the pair representation appends the absolute difference between training-standardized trace summaries. In the selected conditional fusion, these differences are multiplied by command similarity before concatenation with $E$. B/S/T are evidence features for the pair classifier; the task, execution role, source, and path are not model inputs. The classifiers are RBF-SVM, a decision tree, and XGBoost. Their scores are not calibrated probabilities. If either trace lacks a complete required block, the pair uses the same-fold E-only score and threshold; these fallback decisions remain in the evaluation.

\subsection{Pairing and validation}
\paragraph{Exact CTH role mixture.} The frozen CTH core has 17 task groups. In 170 coupled allocations, 16 tasks contribute query and candidate roles, with exactly 0, 8, 16, 24, or 32 Agent roles among the 32 allocated roles. Each query has one same-task and three different-task candidates. Candidate tasks and draws are paired across shares. The share is therefore a property of the constructed query galleries, not a resampled proportion of all source records. We retain the earlier command- and action-bigram-cosine baselines to describe this protocol.

\paragraph{Matched classifier and ablation tests.} The main CTH comparison uses the same 54,400 candidate-pair decisions for E and E+B/S across all five shares and all three learners. AIT contains 109 independent troubleshooting runs across 12 tasks; each configuration uses the same 43,600 pair decisions, with T computed from recorded launch timestamps. NYU contains 585 runs from four snapshots of one Agent framework, grouped into 160 challenge tasks not used in CTH development. Every NYU query is tested against one same-challenge and three different-challenge candidates. This is an AA-only cross-source test, and a challenge filename is the task-retrieval proxy.

Preprocessing, representation choice, classifier parameters, and thresholds are selected within task-disjoint training folds. Each evidence arm selects its threshold on inner out-of-fold predictions under the FMR-at-most-10\% rule; the selected threshold is fixed for the outer evaluation. This constraint is not expected to transfer to the test tasks. CTH results average task outcomes and then the five shares equally; AIT and NYU average task outcomes. We use 10,000 paired task-cluster bootstrap resamples for intervals. Repeated gallery draws and pair decisions within a task are not independent observations, so intervals describe task-cluster uncertainty and remain approximate under shared candidates. No results are adjusted for the many development analyses.

We report balanced accuracy (BA), false-merge rate (FMR), and false-split rate (FSR), where $\mathrm{BA}=1-(\mathrm{FMR}+\mathrm{FSR})/2$. Increasing one error can therefore be hidden by a reduction in the other; all three measures are shown.

\section{Results}
\subsection{The mixture baseline shifts toward missed links}
Figure~\ref{fig:exact-mixture} shows both error rates and BA under the exact CTH role mixture. Command-cosine BA changes from 53.59\% at 0\% Agent roles to 46.50\% at 100\% (endpoint difference $-7.10\pp$, 95\% task interval $[-15.45,+0.06]$). Action-bigram BA changes from 57.40\% to 46.48\% ($-10.92\pp$, $[-20.61,-3.06]$). At the fixed threshold, missed links increase and false merges decrease from the first endpoint to the last.

\subsection{Matched CTH learners do not show a common B/S gain}
Figure~\ref{fig:cth-five-share} shows the same-pair E and E+B/S curves. Averaged equally over the five shares, the XGBoost B/S arm changes BA by $-2.38\pp$ (95\% paired interval $[-7.13,+2.25]$), while FMR rises 9.46 points and FSR falls 4.70 points. SVM changes BA by $+1.38\pp$ $[-3.83,+6.53]$; its mean FMR also rises. The decision-tree B/S version rejects every candidate, giving 50\% BA, zero FMR, and 100\% FSR. None of the three learners satisfies the pre-specified requirement of a stable gain without an error trade-off. The small, five-share changes are made explicit in Figure~\ref{fig:cth-delta}; the intervals cross zero.

\subsection{Pair type changes the error pattern, not the conclusion}
We reuse the same XGBoost predictions and average only the shares where each candidate-pair type exists. For HH, the BA difference is $-8.84\pp$ $[-20.34,+1.67]$; HA is $+1.29\pp$ $[-1.78,+4.71]$; AA is $+1.39\pp$ $[-5.80,+8.03]$. HA and AA point gains accompany higher FMR, while HH trends downward in BA. No stratum establishes a reliable gain. Pair types describe the modes assigned to the two traces and say nothing about whether their behaviors came from the same real attack or operator (Appendix~\ref{app:pair-types}).

\subsection{AIT timing and external Agent-only transfer}
On the AIT association task proxy, adding measured T to E+B/S changes BA by $+0.98\pp$ $[-0.21,+2.10]$; the interval spans zero. Removing a single fingerprint block did not isolate a reliable BA benefit in the matched CTH or AIT comparisons. AIT task and collection workflow co-vary with its execution labels, so the timing contrast is limited to this troubleshooting cohort.

On frozen NYU Agent-only challenge retrieval, adding B/S improves BA by $+5.71\pp$ $[+3.63,+7.73]$ for XGBoost and $+3.64\pp$ $[+1.97,+5.37]$ for the decision tree. With XGBoost, FSR falls from 86.96\% to 60.86\% and FMR rises from 10.72\% to 25.39\%. The tree shows the same error trade-off. SVM BA falls by $8.23\pp$ $[-10.22,-6.28]$. XGBoost also ranks the same-challenge candidate first more often, with a Hit@1 gain of $+3.20\pp$ $[+0.45,+5.90]$ (Appendix~\ref{app:nyu}).

\section{Discussion}
On NYU, the reduction in missed links outweighs the increase in false merges for XGBoost and the decision tree under BA's equal weighting of the two error rates. XGBoost's Hit@1 gain supports using its score to prioritize candidates for review on this benchmark. For automatic linking, the observed 25.39\% FMR with B/S exceeds the 10\% validation ceiling used to select the threshold on CTH. These two uses put different demands on the score and its decision threshold.

The HH/HA/AA breakdown shows why a single overall average is incomplete, but it is descriptive. Its share support and task candidates overlap, and there is no independent mixed-role confirmation dataset. The AIT timing block can be computed from real timestamps, yet its association increment is uncertain and its labels are entangled with task and collection workflow. These results do not identify what caused a particular pair to differ; similar Agent paths, changed execution paths, collection-interface differences, and threshold transfer remain plausible contributors.

All relations are benchmark-task proxies; independent attack-activity labels are absent. CTH terminal and Agent tool-call capture differ, and NYU's snapshots share one framework. Repeated draws do not add independent tasks. Because several alternatives were inspected during development, intervals are exploratory and unadjusted; operational linkage and attribution remain untested.

\section{Conclusion}
On external Agent-only challenge retrieval, B/S improves balanced accuracy for XGBoost and the decision tree, with fewer missed links and more false merges. XGBoost also improves the ranking of the correct candidate. SVM loses BA on the same pairs, and the five-share CTH experiment and AIT timing ablation leave their respective BA increments uncertain. For pair decisions, reporting both error rates alongside BA makes the cost of recovering more links visible.

\section{Frozen external evaluation protocol}\label{app:nyu}
The NYU task manifest was frozen before fitting. Four public D-CIPHER snapshots from the official NYU-LLM-CTF leaderboard-submissions repository were included~\cite{nyu}. The exact source revision and hashes are in the frozen evaluation manifest. Challenge groups overlapping the CTH development pool and one duplicate command sequence were removed. The remaining 160 groups and 585 runs were partitioned by a fixed hash into three retrieval galleries. For each run query, 100 deterministic draws selected one other run from the same challenge and one run from each of three different challenges in the same partition. All three classifiers and both feature arms used the identical 234,000-pair list. Training used only the 17 CTH development task groups and all available training pairs; model parameters and thresholds were not selected from NYU outcomes. The CTH-derived threshold did not preserve its target FMR on the external source.

The official repository and snapshot metadata identify challenge filenames and run configuration. A shared challenge name is only the relation proxy. The four snapshots all belong to one Agent framework; this dataset cannot test Human--Agent associations or activity/actor attribution. Error transitions are counts of repeated pair decisions, not independent events: XGBoost corrected 11,241 earlier false merges and introduced 37,348 new false merges, while it corrected 19,708 earlier false splits and introduced 4,329 new false splits. These counts explain the rate changes but do not increase the independent sample size.

\section{Pair-type support and interpretation}\label{app:pair-types}
The CTH type-specific estimates reuse the outer predictions. HH is supported at 0--75\% Agent roles, HA at 25--75\%, and AA at 25--100\%. Each type is averaged equally across the shares where it exists and then across tasks. At 50\%, the XGBoost gallery contributes 662 positive and 2,004 negative HH pair decisions, 1,396 positive and 4,161 negative HA decisions, and 662 positive and 1,995 negative AA decisions. Pair decisions share queries, candidate tasks, and task clusters; the counts are denominators, not independent sample sizes. The interval widths and overlapping task support preclude interpreting the three rows as independent replications.
