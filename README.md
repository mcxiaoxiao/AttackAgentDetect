The current retrieval experiment uses 177 public CTF traces from 40 task groups. Same-task relevance means the same challenge, not the same attack activity or actor. Execution-mode labels are confounded with capture pathway, and the study has no matched script or activity-level ground truth. The results therefore establish a bounded feasibility finding, not APT attribution performance.
