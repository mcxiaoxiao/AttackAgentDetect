# Paper-ready experiment section

This folder contains a standalone LaTeX packet for the current cross-benchmark prototype study. The draft is written in English for direct reuse in a paper.

- `experiment-results.tex` contains the main experimental setup, findings, and two primary figures.
- `appendix.tex` contains data composition, feature and split details, complete metrics, controls, figures, inference scope, and reproduction steps.
- `main.tex` is a minimal wrapper that compiles those sections together.
- `figures/` contains vector PDF masters and 300-dpi PNG previews.

The figures are generated by [`scripts/generate_paper_figures.py`](../scripts/generate_paper_figures.py). Keep that source with the project: it reads the committed aggregate JSON outputs and reproduces every figure without loading raw traces. Run it from the repository root with:

```bash
.venv/bin/python scripts/generate_paper_figures.py
```

The paper claim is intentionally focused: same-task behavioral retrieval is measurable under same-benchmark hard negatives, while execution-mode scores alter ranking differently across query directions. The underlying labels and matching target come from public CTF traces; the draft does not present them as APT-activity ground truth.

When integrating into a paper, copy `experiment-results.tex`, add the packages and `\RecallAtOne` macro from `main.tex` if absent, and copy the referenced vector figures into the paper's figure directory. The wrapper is useful for checking this packet independently of a full manuscript.
