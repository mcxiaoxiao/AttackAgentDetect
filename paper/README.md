# Paper-ready experiment section

This folder contains a standalone LaTeX packet for the current cross-benchmark prototype study. The draft is written in English for direct reuse in a paper.

- `experiment-results.tex` contains the main experimental setup and interpretation of task-level retrieval and mode-specificity controls.
- `appendix.tex` contains data composition, feature and split details, full metrics, gallery-protocol controls, figures, inference scope, and reproduction steps.
- `main.tex` is a minimal wrapper that compiles those sections together.
- `figures/` contains vector PDF masters and 300-dpi PNG previews.
- `figure3_specificity_controls` compares mode scores with length and nonlinear controls under both gallery protocols; `figureA4_mode_confusions` shows the class-wise error counts.
- Both figure sources are retained in `scripts/generate_paper_figures.py`; the specificity experiment is rerun with `scripts/run_specificity_controls.py`.
- `notebooks/03_specificity_controls.ipynb` reruns the same fixed-fold controls and renders the result tables and figures interactively.

The figures are generated by [`scripts/generate_paper_figures.py`](../scripts/generate_paper_figures.py). Keep that source with the project: it reads the committed aggregate JSON outputs and reproduces every figure without loading raw traces. Run it from the repository root after the experiment scripts:

```bash
.venv/bin/python scripts/generate_paper_figures.py
```

The current evidence shows that same-task retrieval is measurable, while mode-score gains are not specific to mode supervision and disappear with a held-out-only candidate gallery. The underlying labels come from public CTF task IDs, not independently verified attack activities. The draft therefore treats the association application as a hypothesis for controlled testing, not a demonstrated APT result.

When integrating into a paper, copy `experiment-results.tex`, add the packages and `\RecallAtOne` macro from `main.tex` if absent, and copy the referenced vector figures into the paper's figure directory. The wrapper is useful for checking this packet independently of a full manuscript.
